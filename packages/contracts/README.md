# contracts

Fonte única dos contratos (REQ-FND-070): OpenAPI 3.1 em `openapi/`, AsyncAPI 3.0 em `asyncapi/`, JSON Schemas em `schemas/` e contratos de UI em `ui/`. Os clientes são gerados a partir daqui (`pnpm contracts:generate`); mudança incompatível sem nova versão falha no PR (`pnpm contracts:breaking`).
